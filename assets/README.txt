Optional custom sounds
======================

Put these files in this folder:

click.wav  - played for every compression input
guide.wav  - played by the 110 CPM sound guide

If either file is missing or cannot be loaded, the game automatically uses its generated fallback sound for that sound only.

For the most reliable custom-audio test, serve the project through HTTP/HTTPS (GitHub Pages is ideal). Some browsers restrict fetch() for local file:// pages.
